# AI Agent Learning

面向高级前端工程师的 AI Agent 工程转型项目：用 24 周、每周约 10 小时，以原理优先、亲手实现优先的方式，完成从 LLM 接口到可上线 Agent 系统的学习闭环。

## 学习原则

1. **先原理，后框架**：先理解模型调用、上下文、工具、检索与状态机，再使用 LangGraph 等框架。
2. **先单体，后协作**：先把一个 Agent 做可观测、可测试、可恢复，再讨论多 Agent。
3. **先可运行，后炫技**：每个阶段都产出可验证的程序、实验记录或设计复盘。
4. **Python 为主，前端为优势**：Agent 运行时与服务侧使用 Python；你的 TypeScript、Vue、React 能力用于后续产品化与可视化。

## 每周节奏（约 10 小时）

| 时间 | 固定动作 |
| --- | --- |
| 3 小时 | 阅读原理资料并写下自己的解释 |
| 5 小时 | 完成 Python 实现、测试与可复现实验 |
| 1 小时 | 构造评估样例，记录成本、延迟与失败案例 |
| 1 小时 | 复盘并更新 GitHub 任务状态 |

## 当前阶段：第 1–4 周
