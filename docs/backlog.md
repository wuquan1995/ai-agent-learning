# Phase 1 任务看板：Python 与 LLM 接口（第 1–4 周）

每周固定投入 **10 小时**：**3 小时原理阅读 + 5 小时实现与测试 + 1 小时评估 + 1 小时复盘**。完成后勾选任务，并将实验命令、结果和失败案例记录在当周提交或 Issue 中。

## Week 1：Python、HTTP 与密钥边界

- [ ] **3 小时原理：** 学习 Python 虚拟环境、包管理、类型标注、日志、HTTP 请求生命周期、状态码、JSON 和环境变量。
- [ ] **5 小时实现与测试：** 创建 Python 项目；实现一个读取环境变量 token 的 API 客户端；为成功、超时、认证失败和非 2xx 响应各写一个测试。
- [ ] **1 小时评估：** 对比 Node.js 与 Python 的依赖管理、异常处理和测试体验；记录至少三点差异。
- [ ] **1 小时复盘：** 写下密钥绝不能进入源码、Git、日志和提示词的原因。
- **完成标准：** `python -m` 可运行客户端；测试可区分网络、认证和服务端错误。

## Week 2：消息、上下文与调用观测

- [ ] **3 小时原理：** 学习 system、user、assistant、tool 消息语义；理解 token、上下文窗口、采样参数与截断策略。
- [ ] **5 小时实现与测试：** 保存多轮消息为 JSON；实现上下文裁剪；封装调用计时、请求 ID、输入输出 token 和成本估算日志。
- [ ] **1 小时评估：** 选择三个不同长度的对话，比较裁剪前后的消息数、token 估算和回答可用性。
- [ ] **1 小时复盘：** 用自己的话解释短期会话历史、长期记忆和观测日志的边界。
- **完成标准：** 每次调用都生成结构化观测记录，且裁剪策略可由测试覆盖。

## Week 3：结构化输出、工具与提示注入边界

- [ ] **3 小时原理：** 学习 JSON Schema、Pydantic 校验、函数工具契约、直接/间接提示注入与数据/指令分离。
- [ ] **5 小时实现与测试：** 实现一个 Pydantic 结构化任务计划；注册计算器和时间转换两个只读工具；为无效参数、工具异常和注入样本写测试。
- [ ] **1 小时评估：** 对比自由文本解析与结构化输出的失败率；记录每个工具的读取、写入和外部副作用等级。
- [ ] **1 小时复盘：** 写下三条工具权限规则和三条不可信外部内容处理规则。
- **完成标准：** 无效模型输出和注入样本均不能进入未授权工具调用路径。

## Week 4：可观测 CLI 助手

- [ ] **3 小时原理：** 复习模型、上下文、结构化输出、工具契约和可观测性如何组合成最小 Agent 应用。
- [ ] **5 小时实现与测试：** 完成 CLI 助手：支持一项结构化任务和至少一个受控工具；为成功、校验失败和工具失败路径编写测试。
- [ ] **1 小时评估：** 运行至少五个固定样例，汇总成功率、耗时、token/成本估算和工具事件。
- [ ] **1 小时复盘：** 发布阶段总结：已掌握的机制、未解决问题、下一阶段单 Agent 要验证的假设。
- **完成标准：** 提供可复现命令和示例输出；每次运行记录输入、输出、耗时、token/成本估算、工具事件与一条失败轨迹。
